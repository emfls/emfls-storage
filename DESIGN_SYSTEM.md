# Design System

The Foundation implementation follows the independent direction in the Site
Control Page; it is intentionally a small site-specific system, not a full
polish pass.

## Foundation direction

- Light neutral background with muted blue and restrained terracotta accents.
- Editorial layout with clear storage-zone and category labels.
- Semantic landmarks, visible keyboard focus, skip link, readable contrast, and
  responsive navigation/content.
- No copied EMFLS skin, fake illustrations, product-heavy presentation, or
  unnecessary remote assets.

Use this as the bounded foundation identity. Defer fine visual polish until the
network-wide Foundation/Search Launch pass is complete.
