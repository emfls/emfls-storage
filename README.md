# emfls-storage

EMFLS Network site repository.

- Site No.: 16
- Repository: `emfls/emfls-storage`
- Domain: `https://storage.emfls.com/`
- Framework: Astro + TypeScript
- Output: Static
- Current work: Site 16 Foundation / Search Launch horizontal pass
- Search activation: Foundation is live; Google property/sitemap are submitted.
  Naver needs an authenticated Search Advisor session, Daum is unregistered and
  its form stopped at required applicant consent, and IndexNow key validation
  is still pending after two HTTP 202 responses.

The small foundation presents a storage method (classify, locate, measure,
maintain), Trust routes, route-specific metadata, `robots.txt`, an XML sitemap,
a custom noindex 404, and the public IndexNow key file. Deep guides, advanced
tools, detailed visual polish, and AdSense optimization are deferred until the
network-wide Foundation/Search Launch pass is complete.

The existing Cloudflare Pages project and active custom domain were verified;
the Foundation is now live on Production. Production route/visual QA is
documented in [PROJECT_HISTORY.md](PROJECT_HISTORY.md); provider acceptance is
not the same as indexing. See [LAUNCH_CHECKLIST.md](LAUNCH_CHECKLIST.md) for
remaining evidence and blockers.
